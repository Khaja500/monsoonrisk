# MonsoonRisk

Pricing India's rainfall derivatives, and an option the issuer can cancel.

**Live site: https://khaja500.github.io/monsoonrisk/**

Two pricing desks in one static page, both backed by real data and a Python
model layer:

- **Part 1 — weather derivatives.** Rainfall index futures and catastrophe bonds
  for Mumbai, Chennai and Bengaluru, built on 45 years of IMD 0.25° gridded
  daily rainfall. The Mumbai model is checked against what NCDEX's traded
  **RAINMUMBAI** contract actually settled at for September 2026. Chennai and
  Bengaluru get newly constructed contracts, priced forward off the weather
  reports published for the 2026 season.
- **Part 2 — the Israeli (game) option.** An American option on the NIFTY 50
  whose issuer may also cancel early for a penalty, which makes the price the
  value of a Dynkin game. Four numerical methods, a validation suite, and a live
  in-browser pricer.

Every published number carries its uncertainty: bond curves carry a bootstrap band
over the 45 observed seasons, the game option carries the spread of its lattice
across step counts, and the seasonal forecast is scored out of sample against simply
quoting the average — and reported as having little skill, because that is what it
has.

|---|---|
| RAINMUMBAI Sep 2026 settlement | **2,243.55 mm** (mean of IMD Colaba 1,957.1 and Santacruz 2,530.0) |

| Trend-adjusted model | 2,539.9 mm — 296 mm high |
| 35-season backtest (walk-forward) | climatology MAE 430 mm, statistical forecast MAE 421 mm; identical in 86% of years |
| Seasonal forecast skill | Niño 3.4 has **no** out-of-sample skill; for Chennai nothing beats climatology at all |
| Mumbai flood bond, expected loss | 4.25% point estimate — but the 45-season record supports **1.50%–7.24%** |
| RAINCHENNAI-C (constructed), today | 729.7 mm fair value, IMD band 647.7 – 811.7 mm |
| RAINBLR-C (constructed), today | 453.9 mm fair value against a 662.3 mm anchor — Karnataka's worst monsoon in 55 years |
| Israeli put struck at spot | price = the penalty **exactly**, until δ passes 4.44% of spot |

## Repository layout

```
config/           cities.yaml, bonds.yaml, game_option.yaml, forecasts.yaml
src/a_rainfall/   data loading, daily normals, season indices, distribution fitting,
                  peaks-over-threshold tails, climate predictors
src/b_bonds/      contracts, risk-premium rules, pricing with uncertainty bands,
                  the index future, the seasonal forecast and its backtest
src/c_game/       binomial tree, Longstaff-Schwartz, finite differences, bracket, NIFTY inputs
src/common/       config, discounting, shared statistics
scripts/          download_imd.py, extract_cities.py, refresh_current_season.py,
                  build_weather_data.py, build_game_data.py, check_freshness.py
tests/            the acceptance tests from the specification (45 tests)
.github/          a daily job that refreshes the live seasons, with a freshness guard
docs/             the site itself (GitHub Pages serves this folder) + notes/
data/processed/   extracted daily series and reference series (committed)
data/raw/         downloads, not committed - see data/raw/README.md
```

## Reproducing it

```bash
pip install -r requirements.txt

python scripts/download_imd.py 1981 2025      # ~25 MB per year from IMD, parallel
python scripts/extract_cities.py              # one daily series per city -> data/processed
python scripts/build_weather_data.py          # -> docs/data/weather.json
python scripts/build_game_data.py             # -> docs/data/game.json
python -m pytest tests/ -q                    # 45 tests

# while a season is running, the daily job does just this much:
python scripts/refresh_current_season.py      # provisional tail + climate indices
python scripts/check_freshness.py             # fails if the data has not moved

python -m http.server --directory docs 8899   # then open http://localhost:8899
```

Every stochastic routine takes an explicit seed, and every published figure is
regenerated by those scripts.

## What is real and what is not

- **Real:** the IMD rainfall data, RAINMUMBAI's contract terms and 2,206.7 mm
  anchor, the published IMD station totals for the 2026 monsoon, IMD's north-east
  monsoon outlook, the Karnataka deficit figures, NOAA's Niño 3.4 and Dipole Mode
  Index, and the NIFTY 50 / India VIX / RBI levels used as market inputs. All are
  dated and sourced on the site.
- **Not real:** the Chennai and Bengaluru contracts, which were constructed for
  this exercise and are labelled as analogues everywhere; the catastrophe bonds,
  since India has no such market; and the Israeli option, which does not trade on
  the NIFTY.

Nothing here is a quote, a recommendation, or investment advice.
